# ZZSNES development package

Adds ROM Manager and the live ZZ9000 temperature footer. ROM Manager provides
folder import, confirmed duplicate-entry removal (files kept), and verified
save backups. Includes the existing FPGA/Soft scanline players and bundled Xanxi
install-missing tools. Only the launcher changed in this snapshot.

Native large-library/copy tests and physical A4000TX fixture tests passed for
both emulators. Tagged beta releases are unchanged. See docs/rom-manager.md
and docs/package-manager.md for usage and the experimental amipkg workflow.
