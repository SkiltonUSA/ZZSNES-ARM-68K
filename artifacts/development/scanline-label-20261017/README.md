# Software scanline control label

Launcher-only update: copy `ZZSNES` into the existing writable application
drawer while its launcher is closed. Keep the player and settings in place.

The existing ZZDosBox-derived ARM scanline routines are unchanged. The Display
setting is now labelled **Software scanlines**, with a tooltip explaining the
separate Workbench effect. This is a development update, not a new tagged release.

This SNES launcher retains the Thin development option and supplemental FX player
selection; use it with the existing matching development players.
