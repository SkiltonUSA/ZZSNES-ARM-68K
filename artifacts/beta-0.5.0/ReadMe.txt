ZZSNES 0.5.0 Beta

Requires ZZ9000 with compatible XACP firmware, Picasso96, AHI and MUI 3.8
or compatible. Tested with XX19c/XACP 1.7 and AmigaOS 3.2.3.
MUI, AmigaOS, firmware and ROMs are not included.

Extract to a writable drawer and open ZZSNES. Keep ZZSnes-ui beside it.
When upgrading, keep Library.cfg, ROMs, States and Snapshots.
Only one Core1 application may run at a time.

Games: Add, Folder, Scan drives, Rename title, confirmed Delete.
Automatic discovery searches mounted volumes, including USB storage.
Delete removes the ROM and its associated saves/captured snapshot.

Display: Fullscreen or Workbench window; Off/Classic/Soft/Gradient scanlines;
optional FPS, aspect correction, borders and edge masks.

Alt+Return: fullscreen/window    F10, Q, Esc: return to library
P: pause    M: mute    F5: save    F8: load    F9: capture artwork

Five save slots per game. About includes credits and the change list.

Source, documentation and beta updates:
https://github.com/SkiltonUSA/ZZSNES-ARM-68K
