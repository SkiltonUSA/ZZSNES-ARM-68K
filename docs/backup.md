# Backup scope

Snapshot created on 10 October 2026 from the active A4000TX development
workspace. Contains Mesen CPU/system/MUI work, PocketSNES adapters, shared
ARM/68k launch/MMU dependencies, tests, SNES records, exact tested executables
and ELF payloads, original checkerboard, pinned sources and runtime-library
source plus its exact cached link archive.

This separate development repository is not the workspace's original full
Git history, a bootable Amiga image or a physical SD-card backup. Commercial
games, attached disks, firmware, OS installations, credentials, MCP settings
and generated tool installations are excluded. Small runtime helpers retain
historical directory names; unrelated game projects are not included.

Historical logs/manifests preserve original dates and workstation paths. The
Amiga clock was not authoritative; report dates use the Mac session. Raw logs
retain measured values. README distinguishes physical results and pending work.
