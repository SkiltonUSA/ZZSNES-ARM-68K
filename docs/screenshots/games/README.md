# Game captures

Full 320×240 framebuffer captures taken on the physical A4000TX/ZZ9000 with the installed 0.6.5-dev player. These replace the earlier 128×112 title/intro previews. Images are unaltered; FPS overlays were disabled.

All capture sessions returned normally with zero register mismatches, a clean cache witness and owned-memory release. These screenshots are not performance benchmarks or complete-game compatibility tests. The FPGA scanline effect is applied after framebuffer readback and cannot appear in these captures.
