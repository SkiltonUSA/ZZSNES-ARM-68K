# Game captures

[Expanded cartridge tests](../../expanded-cartridges.md). Captures are the original 128×112 previews from the 0.6.4-dev physical runs; the current 0.6.5 Beta also includes subsequent options work.

Images are unaltered Amiga captures. Title/intro captures are labelled accordingly; they do not establish full-game compatibility. Visible FPS is a capture-time diagnostic, not a controlled benchmark. Framebuffer captures omit the FPGA scanline effect.
