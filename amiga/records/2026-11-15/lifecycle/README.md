# Physical lifecycle follow-up

The PPU-row candidate completed 6,000 frames using
Chrono Trigger, Paula AHI and private session/save files.
The log records save, load, screenshot, window 2x → fullscreen → window 2x,
and successful teardown. All 3,208,293 queued PCM frames completed without
device errors. A new process loaded the 1,677,587-byte state and completed
120 frames with register/MMU/cache witnesses and memory release intact.

The run reached its frame limit; the injected F10 was not verified as the
exit cause. This is not a physical joystick or perceptual audio-quality check.
The constant output_hash field is not image-equality evidence. Display switching
uses software scanlines in a window and firmware scanlines in fullscreen.

Source candidate and executable identity are in `manifest.json`. Commercial
ROMs, private checkpoints and screenshots are not included in these records.

A delayed window-activation experiment did not resolve the NES focus check and
was not retained in either production build. No keyboard-exit claim is made.

[Later focus follow-up](focus-followup/README.md) observed concurrent window tests; an isolated rerun is required.
