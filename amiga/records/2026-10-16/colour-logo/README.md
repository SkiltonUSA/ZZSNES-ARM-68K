# Colour logo verification

Both MUI launchers displayed the supplied logos on the A4000TX.
Each MakeIcon wrote and reopened a 64x64 palette-mapped icon and checked its
pixels, dimensions, type, stack, position, default tool and tooltypes.
Installed launchers and icon tools matched the local MD5 values; original
Library.cfg hashes were preserved by installation. No game/player was launched.

The first installed ZZNES window took longer to appear than the empty test
library. An early capture fell back to Workbench; an overlapping input request
timed out. The bridge remained responsive and the launcher subsequently opened.
The successful isolated visual captures and icon round trips preceded this.
No startup-speed or emulation-performance claim is made.
